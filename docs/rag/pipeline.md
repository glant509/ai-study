# 检索流水线

## Ingestion

解析文档时保留标题层级、页码、来源、更新时间、租户与 ACL。Chunk 应尽量保持语义完整；代码、表格和 FAQ 需要不同策略。

## Retrieval

语义向量擅长同义表达，关键词检索擅长专有名词、编号和精确匹配。生产系统常使用 Hybrid Search，再由 reranker 对候选重排。

## Generation

上下文中标注来源边界，要求模型仅依据证据回答；没有足够证据时明确说不知道。引用应指向原始文档，而非仅指向切片 ID。

## 更新与删除

索引是派生数据。建立增量更新、版本切换、删除传播和失败重试机制，确保源数据撤权后索引也及时失效。
