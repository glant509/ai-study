# RAG 评测与优化

把端到端问题拆成可定位的指标。

| 层级 | 问题 | 指标示例 |
|---|---|---|
| 检索 | 正确证据是否被召回 | Recall@K、MRR、nDCG |
| 生成 | 答案是否受证据支持 | Faithfulness、引用正确率 |
| 任务 | 用户目标是否完成 | Task success、人工评分 |
| 系统 | 是否足够快且经济 | P95 延迟、token、成本 |

## 评测集

从真实查询抽样，覆盖无答案、歧义、跨文档、多跳、时效和权限边界。保留标准答案与支持证据，并对数据版本化。

优化顺序通常是先修文档和召回，再调上下文，最后才是 Prompt。不要用更强模型掩盖脏数据或权限错误。
