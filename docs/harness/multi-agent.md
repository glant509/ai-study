# 多 Agent 协作

多 Agent 适合可清晰拆分、能并行验证且通信成本低的任务。它不是提高能力的万能按钮。

## 分工模式

- **Coordinator / Workers**：主 Agent 分解与汇总。
- **Planner / Executors**：计划和执行分离。
- **Maker / Reviewer**：生成与独立验证分离。

## 协作协议

任务描述应包含输入、边界、期望产物、完成标准和禁止动作。共享文件时要划分所有权，避免并发覆盖；结果要引用证据，不只返回结论。

## 成本判断

当任务强耦合、需要大量共享上下文或只有一个写入热点时，单 Agent 通常更可靠。并行的收益必须大于调度、重复 token 和合并冲突的成本。
