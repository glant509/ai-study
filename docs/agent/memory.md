# Memory

Memory 是跨轮次或跨任务保留的信息，不等于把全部聊天记录塞回 Prompt。

| 类型 | 内容 | 典型存储 |
|---|---|---|
| 工作记忆 | 当前计划、变量、未完成步骤 | Runtime state |
| 情节记忆 | 发生过的事件与结果 | Event store |
| 语义记忆 | 稳定事实、偏好、经验 | KV / vector store |
| 程序记忆 | 可复用流程与技能 | Versioned files |

## 写入策略

Memory 写入也应是一个受控决策：判断价值、抽取事实、附带来源与时间、去重、设置有效期。敏感数据必须取得授权并可被删除。

检索时结合相关性、新鲜度、可信度和权限；模型生成的“记忆”不能自动升级为事实。
