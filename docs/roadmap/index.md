# 9 个月学习路线

这条路线利用后端工程经验，逐步叠加模型、Agent 与 AI Infrastructure，而不是从零竞争纯研究岗位。

| 月份 | 主题 | 可验证成果 |
|---:|---|---|
| 1 | Python、NumPy、PyTorch | 训练并部署一个小模型 |
| 2 | Tokenizer、Attention、Transformer | 手写 MiniGPT |
| 3 | Hugging Face、量化、本地模型 | 部署 Qwen / Llama 类模型 |
| 4 | RAG | 带引用与评测的知识库 |
| 5 | Agent Runtime、Tool Calling | 自研最小 Runtime |
| 6 | MCP、Memory、Checkpoint | 可恢复的长任务 Agent |
| 7 | vLLM / SGLang、推理指标 | 模型服务压测报告 |
| 8 | GPU 调度、Kubernetes、观测 | 弹性推理平台原型 |
| 9 | 综合项目 | Agent Platform 作品集 |

## 每周节奏

前 40% 阅读与实验，中间 40% 编码，最后 20% 写复盘和评测。每周都留下代码、图、指标或文档，避免只收藏资料。
