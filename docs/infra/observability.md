# AI 可观测性

传统 RED 指标仍然必要，但 Agent 还需要记录推理轨迹与任务语义。

| 层级 | 观测内容 |
|---|---|
| API | 请求率、错误率、P95/P99 |
| Model | TTFT、TPOT、输入/输出 token、成本 |
| Agent | 步数、工具成功率、重试、终止原因 |
| Quality | 任务成功率、引用正确率、策略违规 |

## Trace 结构

一次 run 是根 span；模型调用、检索、每个工具和审批分别作为子 span。记录模型版本、Prompt 模板版本、工具 schema 版本与数据集版本，才能复现实验。

## 隐私

默认不记录完整 Prompt 和工具结果。采用字段白名单、脱敏、分级保留和访问审计，尤其避免把密钥与个人数据送进第三方追踪平台。
