# 权限、审批与沙箱

## 最小权限

按用户、任务和工具签发短期能力，不向 Agent 注入长期全局密钥。读取与写入分离，文件系统与网络使用 allowlist。

## 风险分级

| 风险 | 示例 | 控制 |
|---|---|---|
| 低 | 搜索公开文档 | 自动执行、限速 |
| 中 | 修改工作区文件 | diff、范围限制、可撤销 |
| 高 | 发消息、部署、付款 | 显式审批、二次校验 |

## 沙箱

限制 CPU、内存、磁盘、执行时间、进程数和出口网络；挂载最小工作目录；执行后销毁环境。沙箱不是单点方案，还需参数验证、策略门和审计。

审批界面应展示具体动作、目标、数据范围和潜在后果，而不是只问“是否允许 Agent 继续”。
