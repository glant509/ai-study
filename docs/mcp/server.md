# MCP Server 实践

## 边界设计

一个 Server 围绕清晰的系统边界组织，例如 GitHub、工单或内部知识库。避免把无关工具堆入“万能 Server”。

## 工具质量

- 名称和描述能区分相似动作。
- JSON Schema 严格限制字段与枚举。
- 分页、限流、超时和取消可预测。
- 错误结果可供模型纠正参数，但不泄漏机密。

## 上线检查

1. 最小权限凭证是否由运行环境注入。
2. 写操作是否有确认或策略门。
3. 日志是否隐藏 token、Cookie 和用户数据。
4. 依赖故障时是否快速失败且可重试。
5. 协议与 schema 变更是否兼容旧 Client。
